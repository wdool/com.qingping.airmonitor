# Changelog

## 1.0.0
- Initial release
- Support for Qingping air quality sensors (CO₂, PM2.5, PM10, temperature, humidity)
- Automatic device discovery via Qingping OAuth API
- Insights for all measurements
- Flow triggers: CO₂, PM2.5, PM10 threshold exceeded
- Flow conditions: CO₂, PM2.5, PM10, humidity above threshold
- Configurable poll interval
- English and Dutch localisation
